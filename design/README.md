# Pass 管理控制台 · 重设计

`admin-console.html` — 可点击高保真原型。浏览器直接打开即可（相对引用同仓 `../ds-bundle/`，无网络依赖）。

## 这份原型建立在什么之上

- **真组件，非仿制**：加载 `../ds-bundle/_ds_bundle.js`，用的是已发布的 34 个 TransCircle 上游组件。
- **真 token，非新造色**：只用 `_ds_bundle.css` 里既有的 66 个 CSS 变量。没有一个字面色值、没有一个不在 4px 刻度上的间距。
- **明暗双主题**：沿用 `[data-theme]` 机制。

## 右下角五个开关

| 开关 | 为什么值得调 |

| 主题 | 明 / 暗 |

## 迁移机制已经实现

`TransCircle-Pass/src/migrations/`：

```
migrator.ts            执行器：整个迁移钉在同一条数据库连接上 + MySQL 命名锁、
                       schema_migrations 账本、幂等 helper（查 information_schema
                       并比对类型/长度/可空性）、replaceCheck、
                       支持 DELIMITER 的 SQL 切分
0001-baseline.ts       检查 7 张核心表：完整则仅登记，全空则导入 schema.sql，残缺则拒绝
0002-admin-console.ts  本次结构变更
src/scripts/migrate.ts pnpm migrate / pnpm migrate:status
tests/migrations.test.ts  18 个单测（本仓第一批测试）
```

启动时自动执行（`src/Index.ts` 的 `bootstrap()` 内，接在连库之后、`listen` 之前）。

**锁怎么做的**：取锁与全部迁移语句跑在**同一条连接**上。锁与写同生共死 —— 连接断了锁自动释放，我们的写也停了。这是真正的 fence，不需要租约、不需要续租、不存在「检查通过但语句已在途」的窗口。

这里连续踩过两次坑，写下来免得后人重犯：

1. **用 `GET_LOCK` 但走连接池** —— 锁在连接 A、`RELEASE_LOCK` 跑在连接 B，释放失败，锁泄漏到进程退出，下一个实例启动卡死。
2. **改成「锁表 + 租约 + 进程内失效标志」** —— 进程内的布尔值挡不住一条**已经发往 MySQL 正在执行**的 DDL。这是 TOCTOU，加再多检查点也消不掉。

**「每步幂等」挡不住并发**：两个实例可能同时查到列不存在、然后同时 `ALTER TABLE ADD`。幂等保证的是**串行重跑**安全，锁是必需品不是优化。

jsdom 里真跑 React，控制台零错误零警告。

**三件没验证的，说在前面：**

1. **视觉未经人眼确认。** 本会话浏览器自动化工具不可用，像素排版、深色主题对比度、悬停/焦点态观感都没看过。
2. **响应式退化未验证。** 表格变卡片走 CSS 容器查询（`@container`），jsdom 不实现容器查询。请把窗口拖到 700px 以下确认。
3. **迁移没有跑过真实 MySQL。** 单测覆盖的是纯函数（类型解析、SQL 切分）；建表、回填、锁竞争都只经过代码审查，没有对着真库执行过。上线前必须在一份生产库快照上演练。

## 建造过程中发现的一个真实缺陷（不在本次范围，建议单独修）

`ds-bundle/_ds_bundle.js` 的 i18n 初始化在模块顶层：

```js
var storedLang = typeof localStorage !== "undefined" ? localStorage.getItem("transcircle-lang") : null;
```

`typeof` 判断挡不住不透明源 —— 属性存在，但一读就抛 `SecurityError`，整个 bundle 在加载期失败、`window.TransCircle` 永不定义，任何以 `file://` 打开的页面都会白屏。本原型加了垫片绕过，**上游应当把它包进 try/catch**（同文件里 `getStoredTheme` 就是这么写的，只有 i18n 这处漏了）。

## 已知取舍

- 原型内的数据是构造的，但**形状**取自真实契约（状态取值域、权限 key、作用域目录、offset 分页的响应结构）。
- 概览的每个数字都是从这份数据算出来的，不是写死的。
- 地址栏是**示意**：展示真实实现中会写进 URL 的内容，原型本身不操作浏览器路由。
- 本文件不实现后端；所有写操作是本地状态。
